# SC用語ドリル v3.0

情報処理安全確保支援士の **科目A-1・科目A-2向け** 4択学習Webアプリ（非公式）。

## 今回の更新

| 指標 | v2.0 | v3.0 |
|---|---:|---:|
| 合計用語 | 696 | 1,846 |
| 科目A-1 | 303 | 973 |
| 科目A-2 | 393 | 873 |
| 分野カテゴリ | 25 | 25 |

- 1,150語を追加（A-1 670語、A-2 480語）。v2.0の説明で「26カテゴリ」としていた分野数は、実数の25に訂正しました。
- 2021年春期〜2025年秋期の10回分について、セキスペ午前Ⅱの全250問を読み、出題語を照合して不足語を追加。
- IPAのシラバス（応用情報 Ver.7.2、セキスペ追補版 Ver.4.0）の用語例から、一般語を除いた試験向けの語を追加。
- 同じ意味の語が別々の選択肢に並ばないよう、既存8語に別名を併記し（例：クレデンシャルスタッフィング（パスワードリスト攻撃））、説明文3語を修正。
- 全1,846語×2出題方式で4択の成立を自動テストし、ヘッドレスブラウザで演習から採点、用語検索までの動作を確認。

### 用語名の正式名表記

v2.0で、英字略称を含む254語に、`DMA（Direct Memory Access）` の形で正式名を追加しました。

学習記録は `科目::用語名` をキーに保存しているため、用語名を変えた語には元の名前を `key` として持たせ、既存の学習履歴とバックアップを引き継げるようにしています。組み込み用語の表示名を変えるときは `key` を削除・変更しないでください。

## 使い方

最初は `index.html` をEdge/Chrome/Safariなどで開いて使用する。Web公開にはGitHub Pagesなどの静的サイトホスティングを利用できる（別途公開設定が必要）。外部のサーバー接続は不要で、オフラインで利用できる。

- 科目A-1 / 科目A-2・分野を選択
- 出題方向：説明から用語を選ぶ、用語から説明を選ぶ
- 学習対象：全用語、未学習、誤答歴あり、復習予定、苦手優先
- 10問 / 20問 / 30問 / 全問
- 学習履歴はブラウザのローカルストレージに保存
- データ管理からCSVで自作問題の追加、JSONで学習履歴のバックアップ・復元

## v1からの移行

既存の161語は **科目と用語の識別子を維持** しています。GitHub Pagesなどで **同じURL（同じオリジン）** の `index.html` を上書きすれば、通常は以前の回答履歴を引き継げます。ただし、ファイルを別の場所から直接開く場合、ブラウザによって保存領域が分かれることがあります。更新前に旧版の「データ管理」からJSONバックアップを取得してください。

## 語彙の精度と限界

このアプリの説明文は公式問題・解答を転載せず、IPAの過去問題、公開シラバス、技術規格を参考に独自に短くまとめたものです。

**過去問との照合範囲は次のとおりです。全用語の網羅を保証するものではありません。**

| 対象（2021年春期〜2025年秋期の10回分） | 照合方法 |
|---|---|
| セキスペ 午前Ⅱ（科目A-2相当） | 全250問を読んで照合 |
| 応用情報 午前（科目A-1の出題元） | 未照合。シラバスの用語例で補完 |
| 応用情報・セキスペ 午後 | 未照合 |

**用語の4択だけで合格に必要な読解・計算・適用力を代替することはできません**。科目A・Bの過去問演習と組み合わせて使用してください。

`校閲レポート.md` に検査内容、照合した情報源、限界を記載しています。CSVを利用者が追加した項目の内容は自動で技術的な真偽を判定しません。
