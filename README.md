# SC用語ドリル v2.0

情報処理安全確保支援士の **科目A-1・科目A-2向け** 4択学習Webアプリ（非公式）。

## 今回の更新

| 指標 | v1.0 | v2.0 |
|---|---:|---:|
| 合計用語 | 161 | 696 |
| 科目A-1 | 72 | 303 |
| 科目A-2 | 89 | 393 |
| 分野カテゴリ | 13 | 26 |

- 535語を追加し、A-1は基礎理論・OS・アルゴリズム・ネットワーク・DB・開発・プロジェクト・経営法務などを、A-2は認証・暗号・攻撃・防御・監視・安全な開発・制御・監査などを拡充。
- 既存161語の説明のうち19項目を修正・明確化（対象は `校閲レポート.md` を参照）。
- 日本語で記述した説明を全用語チェックし、同じ科目内の重複用語・完全一致の説明・説明に正解語が直書きされる例を検出。
- 全696語×2出題方式で、4択が4個の異なる選択肢になり、正解が一つ含まれることをブラウザで自動テスト。
- レスポンシブ表示、10問連続演習、解説・採点・用語検索をブラウザで動作確認。

## 使い方

最初は `index.html` をEdge/Chrome/Safariなどで開いて使用する。Web公開にはGitHub Pagesなどの静的サイトホスティングを利用できる（別途公開設定が必要）。外部のサーバー接続は不要で、オフラインで利用できる。

- 科目A-1 / 科目A-2・分野を選択
- 出題方向：説明から用語を選ぶ、用語から説明を選ぶ
- 学習対象：全用語、未学習、誤答歴あり、復習予定、苦手優先
- 10問 / 20問 / 30問 / 全問
- 学習履歴はブラウザのローカルストレージに保存
- データ管理からCSVで自作問題の追加、JSONで学習履歴のバックアップ・復元

## v1からの移行

既存の161語は **科目と用語の識別子を維持** しています。GitHub Pagesなどで **同じURL（同じオリジン）** の `index.html` を上書きすれば、通常は以前の回答履歴を引き継げます。ただし、ファイルを別の場所から直接開く場合、ブラウザによって保存領域が分かれることがあります。更新前に旧版の「データ管理」からJSONバックアップを取得してください。

## 語彙の精度と限界

このアプリの説明文は公式問題・解答を転載せず、公開されている試験シラバスと技術規格を参考に独自に短くまとめたものです。シラバスの全項目や全年度の過去問を網羅したと保証するものではありません。**用語の4択だけで合格に必要な読解・計算・適用力を代替することはできません**。科目A・Bの過去問演習と組み合わせて使用してください。

`校閲レポート.md` に検査内容、19件の修正対象、照合した情報源、限界を記載しています。CSVを利用者が追加した項目の内容は自動で技術的な真偽を判定しません。
